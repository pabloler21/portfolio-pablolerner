# Mundo PBR — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que la atmósfera de la escena 3D pase a PBR iluminado con sombras, de modo que el personaje deje de leerse como una antorcha naranja pegada encima y pertenezca al mundo — sin que la interfaz pierda su planitud gráfica.

**Architecture:** Todo el cambio vive en un único componente, `src/components/ui/PortfolioScene.astro`. Se toca el pipeline del renderer (tone mapping + shadow map), la construcción de materiales en `buildStreet()` / `buildCityDressing()`, el bloque de luces de `init()`, y el tick para el presupuesto rotativo de farolas. La partición es la de §2 de la spec: la atmósfera se ilumina, la información no. Como el repo no tiene framework de tests unitarios, el ciclo rojo→verde de cada tarea se monta sobre el arnés de aceptación que ya existe, `scripts/verify-ui.mjs`, más una captura visual reproducible.

**Tech Stack:** Astro 7 · Three.js 0.185 (`MeshStandardMaterial`, `PCFSoftShadowMap`, `ACESFilmicToneMapping`, `UnrealBloomPass`) · Playwright-core sobre Chromium SwiftShader para el arnés.

**Spec:** `docs/superpowers/specs/2026-09-06-mundo-pbr-design.md`

## Global Constraints

- **Principio rector (spec §2):** la luz es del mundo, la interfaz no se ilumina. Atmósfera (asfalto, veredas, edificios, postes, líneas de carril) → PBR. Información (carteles, end-cap, HUD, minimapa, chevrons, anillos, unit tag, dossier, neones, skyline, ventanas, glows) → intacta, `MeshBasic`, self-lit.
- **Calibración A2, valores exactos:** `toneMappingExposure` 1.25 · `HemisphereLight` 2.0 · `AmbientLight` 0.85 · `DirectionalLight` 1.7 · farolas 8 × intensidad 24, distancia 16, decay 2, color `0xcfe3d8`.
- **Materiales PBR:** `roughness: 0.93`, `metalness: 0.04`.
- **Los materiales PBR se construyen desde el origen, nunca por `traverse` post-hoc** (lección 17 de CLAUDE.md).
- **La cantidad de luces de la escena es constante en runtime.** Cambiarla recompila el shader de todos los materiales iluminados. El presupuesto de farolas es un pool fijo de 8 que se reposiciona.
- **Una sola luz con `castShadow`:** la direccional.
- **El GLB del personaje no se toca.** Mismos materiales, mismo rig, mismos clips.
- **`prefers-reduced-motion`:** PBR y sombras quedan activos. El guard sigue aplicando sólo a bloom e intro (lección 8).
- **Zero `border-radius`** y demás constraints de CLAUDE.md siguen vigentes — este plan no toca CSS.
- **WSL2:** nunca `npx astro dev`; sólo `npm run dev` sin flags. Reiniciar y verificar servidores en la MISMA llamada de Bash (lección 4).

function resolveChrome() {
  if (process.env.CHROME_PATH) return process.env.CHROME_PATH;
  const base = path.join(process.env.HOME, '.cache/ms-playwright');
  for (const d of readdirSync(base).filter(x => x.startsWith('chromium-'))) {
    const p = path.join(base, d, 'chrome-linux64', 'chrome');
    if (existsSync(p)) return p;
  }
  throw new Error('No se encontró chromium. Definí CHROME_PATH.');
}

function browserEnv() {
  const libs = path.join(ROOT, '.cache/pw-libs/root/usr/lib/x86_64-linux-gnu');
  if (!existsSync(libs)) return process.env;
  const prev = process.env.LD_LIBRARY_PATH;
  return { ...process.env, LD_LIBRARY_PATH: prev ? `${libs}:${prev}` : libs };
}

const srv = await new Promise(resolve => {
  const s = createServer(async (req, res) => {
    let p = decodeURIComponent(req.url.split('?')[0]);
    if (p.endsWith('/')) p += 'index.html';
    const f = path.join(DIST, p);
    if (!f.startsWith(DIST)) { res.writeHead(403).end(); return; }
    try {
      const b = await readFile(f);
      res.writeHead(200, { 'Content-Type': MIME[path.extname(f)] || 'application/octet-stream' });
      res.end(b);
    } catch { res.writeHead(404).end('not found'); }
  });
